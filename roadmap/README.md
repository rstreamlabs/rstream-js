# JavaScript SDK roadmap

These proposals track future contributor tooling and protocol work. See the
[SDK guides](../docs/README.md) for current package capabilities.

| Proposal                                                        | Acceptance boundary                                                                        |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| [001 Node build toolchain](001-node-build-toolchain.md)         | Qualify build, lint and release consumers without changing published runtime requirements. |
| [002 Build and release majors](002-build-and-release-majors.md) | Qualify compiler, lint and release tooling together.                                       |
| [003 WebTTY cipher suites](003-webtty-cipher-suites.md)         | Verify browser support, negotiated profiles and shared Go and C++ vectors.                 |
